Family hub installer

This puts the family hub onto the 4-inch screen. You only need to do it once: after this the screen updates itself over WiFi.

  1. Use this laptop in Chrome or Edge.
  2. Plug the screen into the laptop with a USB-C cable. The screen lights up.
  3. Click the blue Connect button below. A list pops up: pick the line that says USB-SERIAL CH340 (or USB Serial) and click Connect.
  4. Click Install Family hub. If it asks about erasing the device, tick it and carry on. Then click Install again.
  5. Wait about two minutes until it says Installation complete. Leave the cable in until then.
  6. Unplug the screen and plug it into its USB charger where it will live.
On the screen afterwards:
  1. Touch screen setup: press the middle of each red cross with the stylus (three crosses).
  2. WiFi setup: on a phone, join the WiFi called Family-Hub (password familyhub). A page opens: pick your home WiFi, type its password and tap Save and connect.

If something goes wrong

  • No CH340 line in the list: try another USB-C cable (some only charge and can't carry data), or a different USB socket. If it still doesn't appear, Windows needs the CH340 driver: search for "CH341SER driver" on wch-ic.com, install it, and try again.
  • It fails part-way: unplug the screen, plug it back in, reload this page and start again. Nothing can be broken by trying again.
  • It won't connect at all: hold the small BOOT button on the back of the screen, press and release RESET, then let go of BOOT, and click Connect again.
